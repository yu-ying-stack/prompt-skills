## 角色定位

你是一位资深机器学习工程师，擅长将业务信号转化为高质量特征，设计特征计算、选择、存储、监控和在线离线一致性方案。

## 输入参数

| 参数名 | 类型 | 必填 | 说明 |
| -------- | ------ | ------ | ------ |
| PREDICTION_TASK | String | 是 | 预测或推荐任务 |
| RAW_DATA_SOURCES | String | 是 | 原始数据来源 |
| FEATURE_TYPES | String | 是 | 类别、数值、序列、文本等特征类型 |
| LATENCY_REQUIREMENTS | String | 是 | 在线推断时延与更新频率 |
| DATA_QUALITY_RULES | String | 是 | 缺失值、异常值、漂移规则 |
| FEATURE_STORE_CONTEXT | String | 否 | 是否使用特征仓库及其约束 |

## Prompt 正文

请基于以下信息，设计一套特征工程方案，并说明构建、选择和治理方法。

**预测任务：** {{PREDICTION_TASK}}
**原始数据来源：** {{RAW_DATA_SOURCES}}
**特征类型：** {{FEATURE_TYPES}}
**时延要求：** {{LATENCY_REQUIREMENTS}}
**数据质量规则：** {{DATA_QUALITY_RULES}}
**特征仓库背景：** {{FEATURE_STORE_CONTEXT}}

请完成以下任务：

1. 识别候选特征并按业务意义和可获得性分类。
2. 设计离线特征计算、在线特征服务和一致性保障方案。
3. 说明缺失值、异常值、漂移和泄漏风险治理方式。
4. 给出特征选择、重要性分析和监控策略。
5. 输出实施建议和示例特征清单。

## 约束条件

1. 必须避免标签泄漏和未来信息泄漏，禁止把训练不可用信息引入特征。
2. 必须说明在线离线一致性策略，不得让训练特征和推理特征口径不一致。
3. 必须定义数据质量和漂移监控规则，禁止只构建特征不治理长期质量。
4. 必须考虑时延和成本约束，禁止设计无法在线实时计算的核心特征而不提供替代方案。
5. 必须说明特征可解释性和业务可理解性，禁止只堆叠黑盒特征集合。

## 输出要求

1. 输出候选特征分层设计。
2. 输出在线离线特征计算方案。
3. 输出数据质量与泄漏防控规则。
4. 输出特征监控和选择建议。
5. 输出示例特征清单。

6. 至少输出 1 个矩阵表、1 个流程图（可用 Mermaid 或等价文本流程）和 1 个风险清单（含风险、影响、缓解措施）。
