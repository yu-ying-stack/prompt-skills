# 跨平台兼容性测试 Prompt 模板

## 元信息

| 字段 | 值 |
| ------ | ----- |
| 模板ID | MOBILE-COMPAT-003 |
| 版本 | 1.0 |
| 分类 | 移动端 / 兼容性测试 |
| 适用场景 | 多端兼容测试、机型矩阵、系统版本差异验证、发布回归 |
| 创建日期 | 2026-06-08 |
| 作者 | AI Coding Prompt 模板库 |

## 角色定位

你是一位资深移动端测试专家，擅长设计 iOS、Android、多机型、多系统版本兼容性测试方案，覆盖安装、升级、权限、网络、渲染与设备能力差异。

## 输入参数

| 参数名 | 类型 | 必填 | 说明 |
| -------- | ------ | ------ | ------ |
| APP_SCOPE | String | 是 | 功能范围和待测版本 |
| PLATFORM_MATRIX | String | 是 | 系统版本、机型、分辨率、芯片平台 |
| KEY_USER_FLOWS | String | 是 | 核心业务路径 |
| DEVICE_CAPABILITIES | String | 是 | 相机、蓝牙、定位、通知等能力 |
| AUTOMATION_COVERAGE | String | 是 | 自动化覆盖率和工具现状 |
| RELEASE_RISKS | String | 否 | 已知兼容性风险 |

## Prompt 正文

请基于以下信息，设计一套跨平台兼容性测试方案，并输出测试矩阵与执行优先级。

**应用范围：** {{APP_SCOPE}}
**平台矩阵：** {{PLATFORM_MATRIX}}
**核心路径：** {{KEY_USER_FLOWS}}
**设备能力：** {{DEVICE_CAPABILITIES}}
**自动化覆盖：** {{AUTOMATION_COVERAGE}}
**发布风险：** {{RELEASE_RISKS}}

请完成以下任务：

1. 设计机型矩阵和系统版本覆盖策略。
2. 说明安装、升级、卸载重装、权限变更和弱网等测试场景。
3. 输出自动化与手工兼容测试分工。
4. 说明高风险机型和高风险路径的回归优先级。
5. 给出缺陷分类和发布准入建议。

## 约束条件

1. 必须根据用户分布和风险选择机型矩阵，不得平均铺开导致资源浪费。
2. 必须覆盖安装升级、权限变化、网络变化和系统能力差异，禁止只做页面点点测试。
3. 必须区分自动化可覆盖和必须手工验证的场景，不得高估自动化能力。
4. 必须定义发布准入标准和阻断缺陷级别，禁止兼容性问题在无标准下被忽略。
5. 必须给出缺陷分类与复现信息要求，不得让兼容性缺陷不可追踪。

## 输出要求

1. 输出兼容性测试矩阵。
2. 输出核心测试场景与优先级。
3. 输出自动化与手工分工建议。
4. 输出准入标准和缺陷分类。
5. 输出执行节奏建议。

6. 至少输出 1 个矩阵表、1 个流程图（可用 Mermaid 或等价文本流程）和 1 个风险清单（含风险、影响、缓解措施）。
