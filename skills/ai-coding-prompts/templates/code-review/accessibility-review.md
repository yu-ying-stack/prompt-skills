# 无障碍性审查模板
---
元信息:
	模板名称: accessibility-review
	模板类型: code-review
	适用场景: 针对前端页面/组件做无障碍性（a11y）审查
	版本: 1.0.0
	最后更新: 2026-06-17
---

## 元信息
- 场景: 针对前端页面/组件做无障碍性（a11y）审查

## 输入参数
- `html_or_component`: HTML 片段或组件代码
- `WCAG_level`: 期望的 WCAG 等级（A/AA/AAA）

## Prompt 正文
按照 WCAG 要求列出问题清单、修复建议、以及必要的可访问性测试步骤和自动化检查规则。
